Paper Mario PAL Alpha 0.4 (PAL-0.4-STD)

This is an experimental native port for Miyoo Mini-family devices running Onion OS.
Install by extracting this ZIP at the root of the SD card. It creates
App/PaperMarioPAL/. Supply your own verified Paper Mario (Europe, PAL) ROM:

  /mnt/SDCARD/Roms/N64/PaperMarioPAL.z64

Required ROM SHA-1:
  2111d39265a317414d359e35a7d971c4dfa5f9e1

Start "Paper Mario PAL Alpha 0.4" from Apps. The game stores its own files
under App/PaperMarioPAL/data/. It does not import or alter saves from other
Paper Mario apps. The four PAL language choices are made by the game as
usual. Manual save-states and the game's normal save are different files;
use the menu Save/Load State commands for states and in-game save points for
normal progress.

Alpha status: this package passed static release checks but still requires
hardware acceptance of this exact binary. Do not assume that every historical
renderer issue is resolved. The source port code is under its upstream license;
Paper Mario, its characters, and ROM content are not included or licensed here.
