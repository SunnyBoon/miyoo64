# Known issues — v0.1.1-pal-alpha

- Narrow straight segment seams on some large trees expose the background.
- Goombario's enlarged enemy display has an incomplete frame: two sides instead of four.
- A Star Piece incorrectly blinks instead of remaining statically visible; its shadow remains visible while it disappears.

These graphics issues are unfixed. No renderer/gameplay changes are part of this packaging update.

The retained App label is Paper Mario PAL 0.1-pal-alpha, matching the exact tested ZIP; the release version is v0.1.1-pal-alpha. Both menu entries intentionally share the same App folder and data. The existing OnionOS importer/Ports component is required and not bundled. Only Miyoo Mini Plus with OnionOS has the stated hardware evidence; the exact OS version and test date were not supplied. No full-game or exhaustive late-scene validation is claimed. Do not mix the separate newer-overlay PR build's caches or save states with this build.
